**Pearl Port** is a modern, privacy-focused multi-asset investment portfolio tracker designed specifically for Sri Lankan investors and wealth builders. It brings together CSE equities, Unit Trusts, Fixed Deposits, and Crypto into a unified, mobile-first dashboard.

---

### ✨ Key Features

- **📊 Multi-Asset Portfolio Tracking**:
  - **CSE Equities**: Track Colombo Stock Exchange shares with live/cached prices, average cost calculations, and transaction history.
  - **Unit Trusts (UTASL)**: Monitor Sri Lankan mutual funds with daily NAV updates.
  - **Fixed Deposits**: Manage bank FDs, interest rates, compounding cycles, and maturity dates.
  - **Cryptocurrency**: Track crypto holdings with P2P exchange rate conversions (USDT / LKR).

- **🤖 AI-Powered Portfolio Insights**:
  - Integrated with **Google Gemini AI** to deliver personalized portfolio reviews, risk distribution checks, and rebalancing recommendations.

- **📈 Visual Analytics & Reports**:
  - Dynamic asset allocation charts and sector exposure breakdowns.
  - Realized vs. unrealized profit/loss summaries and dividend income tracking.

- **🔒 100% Privacy & Local Storage**:
  - Zero server-side tracking. All portfolio data stays safely on your device.
  - Offline-first capabilities with fast local caching.

- **📱 Cross-Platform Experience**:
  - Progressive Web App (PWA) with installable home-screen experience.
  - Ready for native iOS & Android packaging via **Capacitor**.
  - Premium Dark & Light mode financial UI.

---

### 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **Mobile**: Capacitor (Android & iOS)
- **AI Integration**: Google Gemini API
- **Deployment**: Firebase Hosting / Netlify / Vercel
